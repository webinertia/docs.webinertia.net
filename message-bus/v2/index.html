    1. Contents

    A command/query message bus for Mezzio/PSR-11 applications. A message (command or query) is handed to a MessageBusInterface, which runs it through a middleware pipeline. The final middleware in that pipeline resolves the mapped handler, chooses the handler method through a StrategyInterface, and invokes it. The result flows back out through the pipeline as a ResultInterface. See Execution Flow for diagrams of how a message moves through the pipeline and back.
